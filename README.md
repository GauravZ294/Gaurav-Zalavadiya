# Gaurav Zalavadiya — Portfolio

A static, dark-only portfolio for AI development and quality engineering.

## Pages

- index.html: introduction, selected projects, career snapshot, service overview, and contact action.
- about.html: biography, portraits, working approach, and languages.
- skills.html: mobile QA, automation, AI development, delivery skills, and reading resources.
- experience.html: complete work history, education, certification, and CV download.
- projects.html: searchable project collection with live-site and case-study filters.
- services.html: full service catalogue and interactive workflow.
- blogs.html: existing personal writing and testing-tool notes.
- contact.html: direct contact details and email-draft form.
- portfolio-details.html?id=1 through id=8: project details.
- blog-details.html and service-details.html: existing detail content.

## Styling and interactions

- assets/css/portfolio-theme.css: visual theme, media ratios, and decorative motion.
- assets/css/modules.css: page layouts, navigation, buttons, and module components.
- assets/js/main.js: navigation and optional library integrations.
- assets/js/studio-motion.js: background, mouse cursor, reveals, and workflow interactions.
- assets/js/modules.js: project search, filters, service enquiries, and legacy hash redirects.
- assets/Resume/Gaurav_Zalavadiya_CV.pdf: supplied CV, copied without altering its contents.

Career and skills sections use inline SVG icons. Decorative effects support pausing and reduced-motion preferences. The native mouse cursor remains available.

## Content notes

The website retains the explicitly supplied career correction: Vasundhara Infotech ended in October 2026 and Semicolon began in October 2026. The supplied PDF is unchanged. Other career details and the contact email follow the supplied CV.

The contact form opens a draft in the visitor's email app. It does not send messages through a server or claim delivery. The visitor must send the draft themselves.

## Preview and deployment

Serve this directory with a static HTTP server. No package installation or build is required. The included vercel.json publishes the directory as a static site; choose the Other framework preset.

Existing homepage bookmarks such as /#portfolio redirect to the corresponding dedicated page.
