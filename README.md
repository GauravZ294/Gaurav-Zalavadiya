# Portfolio Enhanced

A static portfolio website with HTML, CSS, and JavaScript assets.

## Structure

- `index.html` - Homepage
- `blogs.html` - Blog listing
- `blog-details.html` - Blog details page
- `portfolio-details.html` - Portfolio details page
- `service-details.html` - Service details page
- `assets/` - CSS, JS, images, and vendor libraries
- `forms/` - Contact form backend files

## Deploying to Vercel

This is a static site. The included `vercel.json` explicitly disables framework
auto-detection and publishes this directory as-is. In the Vercel project settings,
leave the framework preset as **Other** and do not configure a Python entrypoint or
build command.
